Передай координатору: URL issue/PR, head SHA, изменённые файлы, результат,

## README координатора

Содержит:

1. Общую задачу, родительский issue, исходный SHA, число людей и критерии результата.
2. Таблицу: участник → свой issue → область → ветка → файл задания → результат.
3. Таблицу владения: путь → владелец → этап → условие передачи. Для glob-областей
   явно проверить вложенные пересечения; новые файлы тоже закрепить.
4. Зависимости и порядок PR. Например: контракт → независимые backend/frontend → сквозной прогон.
   Записать фактические номера PR после появления, не выдумывать их в плане.
5. Общие файлы, принадлежащие координатору, и отдельный issue для его реализации, если она есть.
6. Порядок приёмки, проверку совместного сценария, действия при конфликте и закрытие родителя.
7. Указание, какие MD передать людям и какие условия старта ещё не выполнены.

Каждый `<NN>-<owner>.md` должен работать без чтения этого README; внешние зависимости
и ограничения из README повторяются в относящемся к ним индивидуальном задании.
