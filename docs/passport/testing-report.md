## 10. Известные ограничения тестирования

- Метрики качества получены на синтетических данных с заложенными нами схемами: это верхняя оценка, а не подтверждённое качество на реальных реестрах.
- Правила R01–R06 совпадают с разметкой полностью, потому что генератор и правила написаны по одной спецификации.
- Качество LLM измерено только на 30 обращениях; работа LLM на CPU и Ollama в Docker на демо-стенде не замерялись.
- Нагрузочного тестирования не было.
- В прогоне 22.11.2026 не выполнялись тесты бэкенда и фронта, e2e и smoke: в среде нет Docker-демона, Node.js и uv. Проверены данные, генератор и доменная логика на чистом Python.
- Тестов на разграничение доступа нет: аутентификация и роли в прототипе не реализованы.
