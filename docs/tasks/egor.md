# Егор — фронтенд: граф, обращения, слайды

Общий порядок: [workflow.md](../workflow.md). Перед реализацией — GitHub issue,
метка зоны и assignee; ветка от `dev`, рабочий PR в `dev`.
Для разделения работы между людьми — [/task-handoff](../../.agents/skills/task-handoff/SKILL.md).

Ты отвечаешь за самый зрелищный экран (граф связей), за раздел обращений и за презентацию. Типы и API-клиент берёшь у Влада Г. из `src/shared/api`.

Читать перед стартом: [contracts.md](../contracts.md), [frontend.md](../frontend.md), [demo.md](../demo.md).

### F-11. Граф связей: базовый рендер
**КТ:** КТ1 · **Зависит от:** F-02 · **Ссылки:** [contracts.md — API](../contracts.md#api-apiv1)

- Компонент `RelationGraph` на Cytoscape по ответу `/officials/{id}/graph`.
- Форма и цвет узла по типу (`person`, `company`, `organ`, `contract`, `appeal`), рамка по уровню риска, подписи рёбер.
- Раскладка, которая не превращается в клубок на 50–150 узлах. Попробовать `cose` и `breadthfirst` от служащего.
- Легенда типов узлов.

Готово, когда:
- [x] граф H1 на моках читается без зума на экране ноутбука.

### F-12. Граф: подсветка цепочки флага и клики
**КТ:** КТ1 · **Зависит от:** F-11

- Клик по узлу-служащему открывает его профиль, по узлу-обращению — карточку обращения.
- Узел «N контрактов» показывает сумму в подписи.

Готово, когда:
- [x] выбор флага R01 в профиле H1 подсвечивает ровно его цепочку.

### F-15. Карточка обращения с разбором
**КТ:** КТ2 · **Зависит от:** F-13

- Текст с подсветкой сущностей по `start/end`, цвет по типу, легенда.
- Категория, уверенность, риск-сигналы, конкретность, маршрут, краткое содержание.
- Связанные служащие с баллом риска и ссылкой на профиль.
- Пометка, чем сделан разбор: LLM или фоллбэк (если `analysis.engine` приняли в контракт).
- Кнопка «Повторный анализ».

Готово, когда:
- [x] подсветка не съезжает на текстах с кавычками, переносами строк и ёлочками.
