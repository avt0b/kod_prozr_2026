### OPS-02. Образы бэка и фронта, миграции на старте
**КТ:** КТ1 · **Зависит от:** B-01, F-01

- Сверить `backend/Dockerfile` и `frontend/Dockerfile` с compose: точка входа, порт, `VITE_API_URL` как build-arg.
- Бэк применяет миграции перед стартом (`alembic upgrade head`).
- Healthcheck у каждого сервиса, `depends_on` с `condition: service_healthy`.
- Смонтировать `./data:/app/data:ro` в бэкенд: каталога `data/` нет в образе, а загрузчик сидов читает из него.
- Разобраться с сетью Docker на машинах команды: при подготовке `npm ci` внутри контейнера не достучался до registry npm.

Готово, когда:
- [ ] `make build && make up` с нуля даёт работающий фронт на `:3000`, бэк на `:8000`.

### OPS-04. Make-цели под данные и ИИ
**КТ:** КТ1 · **Зависит от:** B-03, AI-02

- `seed` — загрузить синтетику (команду даёт Миша).
- `reset` — снести тома, поднять заново, применить миграции и сиды.
- `data-check` — проверка сгенерированных данных (скрипт даёт Влад О.).
- `eval` — метрики качества (скрипт даёт Влад О.).

Готово, когда:
- [ ] `make reset` за одну команду приводит стенд в состояние «как перед демо».
