## Минимальный жизнеспособный демо (MVP — должен работать при любом раскладе)

1. `make up && make seed` поднимает стенд с синтетикой.
2. Рейтинг служащих по баллу, заложенные кейсы стоят вверху.
3. Профиль: должность, полномочия, родственники, компании, флаги R01–R05 с объяснением, цепочкой и нормой.
4. Граф связей с подсветкой цепочки флага.
5. Новое обращение: анализ (LLM или фоллбэк), привязка к служащему, R07, балл вырос.
6. Черновик докладной по шаблону (без LLM) с дисклеймером «решение принимает человек».

## Если успеваем (в порядке приоритета)

1. R06 (концентрация поставщика) и R08 (ML-аномалии).
2. Метрики качества на синтетике для слайда (`make eval`).
3. Связный текст докладной от LLM поверх шаблона.
4. Журнал действий аналитика в UI.
5. LLM-ассистент аналитика.
6. Вариант D: карта коррупционных рисков должности по тексту регламента.

## Риски и что делаем

| Риск | Реакция |
| --- | --- |
| LLM медленная или недоступна на стенде | Фоллбэк и предрасчитанные анализы. Демо-обращение отрепетировано на фоллбэке тоже. |
| Выгрузки открытых данных недоступны | Работаем только на синтетике со справочниками ОКПД2 и ОКВЭД2 (ADR-06). |
| Граф нечитаем из-за большого числа узлов | `depth=2`, лимит узлов, контракты группируются в один узел «N контрактов». |
| Интеграция фронта и бэка срывает КТ2 | Фронт остаётся на моках, и бэк чинит расхождения с контрактом в приоритете. |
