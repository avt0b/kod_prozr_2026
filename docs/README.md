## Что делаем

Рабочее место аналитика подразделения по профилактике коррупции (вариант C из [variants.html](variants.html)).
- **Цифровой профиль служащего.** Это не досье, а граф: должность → полномочия (закупки, разрешения, проверки, бюджет) ↔ родственники → компании → контракты органа.
- **Объяснимый риск-скоринг.** Правила по 273-ФЗ и 79-ФЗ плюс ML-сравнение с коллегами той же должности. У каждого флага есть объяснение, цепочка связей и ссылка на норму.
- **Анализ обращений граждан через LLM.** Классификация, извлечение сущностей, риск-сигналы, маршрутизация. Упомянутый служащий сопоставляется с профилем, и обращение повышает его риск-балл.
- **Черновик докладной записки** формируется по найденной схеме. Решение принимает человек.
- Доходы и расходы не анализируем: это зона ГИС «Посейдон». Наш фокус — сочетание полномочий служащего и его связей.

## Правила

- Для процесса разработки источник правды — `workflow.md`, для API и модели — `contracts.md`. Если технический документ противоречит `contracts.md`, прав `contracts.md`. Кто меняет контракт, тот обновляет его в том же PR.
- Предложения по изменению контракта, которые появились в этих документах, отмечены пометкой **«→ в контракт»**. Их нужно обсудить и перенести в контракт.
