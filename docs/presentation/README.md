## Исходник

`build.mjs` создаёт редактируемый PPTX и PNG для проверки через встроенный runtime `@oai/artifact-tool`. Запускать из корня репозитория в Codex с переменной `ARTIFACT_TOOL_MODULE`, содержащей file URL установленного `artifact_tool.mjs`, либо с доступным пакетом `@oai/artifact-tool`. Результат сборки находится в `.codex-build/slides/`; это кандидат для проверки, а не автоматическая замена финального файла.

После изменений нужно снова отрендерить каждый слайд, просмотреть его и проверить финальный PPTX. В текущей версии выполнены проверка структуры, геометрии, шрифтов и обратный импорт. Просмотр в Microsoft PowerPoint не выполнялся.
